**Core Technologies**

`Python` `FastAPI` `React` `TypeScript` `RAG`
`LLMs` `ChromaDB` `BM25` `Cross-Encoder`

**Key Features**

- 📄 PDF, DOCX, and TXT document ingestion
- 🔎 Semantic vector retrieval
- 🔀 Hybrid semantic + BM25 retrieval
- 🎯 Cross-encoder reranking
- 🧠 Multi-provider LLM architecture
- 🔌 Configurable LLM providers
- 📚 Source attribution and retrieval explainability
- ⚡ Production-oriented FastAPI backend
